# Telegram цитата бот

Бот для создания стильных фото- и видео-цитат с размытием (glassmorphism), поддержкой GIF, персональных фонов и инлайн-режима.

# Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
pip install -e ./Ataraxis-Python
```

2. Укажите ваши данные в `.env`:
```env
api_id=2040
api_hash=b18441a1ff607e10a989891a5462e627
bot_token=ВАШ_ТОКЕН_БОТА
admin_id=ВАШ_TELEGRAM_ID
ataraxis=
```

3. Запустите бота:
```bash
python main.py
```

# Основные команды

- `/ц`, `!ц`, `ц` (ответом на сообщение) — создать статичную фото-цитату.
- `/гиф`, `!гиф`, `гиф` (ответом на сообщение) — создать живую анимированную GIF-цитату.
- `/ф` (ответом на фото или при отправке фото боту в ЛС) — установить личное фото для цитат.
- `/фс` — сбросить личное фото к стандартному фону.
- `/б <проценты>` (для админа) — изменить процент блюра карточки.
- `/бс` (для админа) — сбросить блюр к дефолтному (25%).
- `/фдефолт` (для админа) — изменить стандартный базовый фон для всех.
- `/help` — список доступных команд.
